# Archive - Previous Design Versions

このフォルダには、開発過程で作成された異なるデザインバリエーションが保存されています。

## フォルダ構成

### `/watercolor-design/`
**オリジナル水彩テーマ**
- `index.html` - 水彩風エレガントデザイン
- `styles.css` - グラス質感とレイヤー構造CSS
- `script.js` - 水彩エフェクトとインタラクション

**特徴:**
- 半透明グラス質感
- 3D浮遊エフェクト（CSS）
- 水彩風カラーパレット
- オーガニックなアニメーション

### `/light-3d-design/`
**明るい3Dキャンバステーマ**
- `index-light.html` - Three.js実装の明るいデザイン  
- `styles-light.css` - 明るい背景のCSS
- `script-light.js` - Three.js 3Dエフェクト実装

**特徴:**
- Three.jsリアルタイム3D
- 明るいクリーム/ホワイト背景
- 実画像統合
- GSAP アニメーション
- パーティクルシステム
